Getting Started

Welcome to Notes! This is a fast, native Linux note-taking application built with Qt and C++17.

Features:

  • Lightning fast performance
  • Auto-save functionality
  • 3-pane layout

Why Choose Notes?

Built by developers, for developers (and maybe some sysadmins too)

Lightning Fast

Native C++ performance with zero Electron bloat. Start instantly and edit without lag. Your CPU will thank you.

Auto-Save

Never lose your work. Every keystroke is automatically saved to SQLite database. Because we've all been there.

3-Pane Layout

Organized workflow with folders, notes list, and editor all visible at once. No more tab switching madness.

Drag & Drop

Intuitive organization with drag and drop support. Move notes between folders like a digital Marie Kondo.

Plain Text

Distraction-free editing with plain text format. Focus on content, not formatting. Markdown is overrated anyway.

Dark Theme

Easy on the eyes with a beautiful dark theme. Because staring at bright screens all day is so 2010.

Architecture

Clean, modular design that even your junior dev can understand

🏗️ How It's Built

Notes follows a clean, layered architecture that separates concerns and makes the codebase maintainable. Each layer has a specific responsibility, making it easy to understand and contribute to.

1

🎨 UI Layer

What users see and interact with

Qt Widgets Native UI components
Custom Components Notes-specific UI elements
Dark Theme Consistent visual design

Responsibility: Handles user interactions, displays data, and manages the visual presentation of the application.

Key Files: MainWindow.cpp, TextEditor.cpp, NoteListDelegate.cpp

2

🧠 Business Logic

Core application functionality

Note Management CRUD operations for notes
Auto-save Engine Automatic data persistence
Folder Organization Hierarchical note structure

Responsibility: Contains the core business rules, orchestrates data flow, and manages application state.

Key Files: MainWindow.cpp (business logic), NotesModel.cpp

3

💾 Data Layer

Reliable data persistence

SQLite Database Local data storage
File System I/O Import/export functionality
Data Migration Schema version management

Responsibility: Handles all data persistence, database operations, and file system interactions.

Key Files: DatabaseManager.cpp, DatabaseManager.h

🎯 Why This Architecture?

Easy to Understand

Clear separation of concerns makes the codebase approachable for new contributors

Easy to Debug

Issues can be isolated to specific layers, making debugging much simpler

Easy to Extend

New features can be added without affecting existing functionality

Easy to Test

Each layer can be tested independently

Get Started in Seconds

Simple installation for Ubuntu/Debian systems (because we're not animals)

Download .deb Package

Recommended
Terminal 
# Download the latest release
wget https://github.com/mustafa-khann/notes/releases/download/v0.1.0/notes_0.1.0-1_amd64.deb

# Install the package
sudo dpkg -i notes_0.1.0-1_amd64.deb

# Fix any dependencies
sudo apt-get install -f

Build from Source

For Developers
Terminal 
# Clone the repository
git clone https://github.com/mustafa-khann/notes.git
cd notes

# Install dependencies
sudo apt-get install qt6-base-dev cmake build-essential

# Build and install
mkdir build && cd build
cmake ..
make
sudo make install
